# Attivita generate

I file JSON di questa cartella vengono prodotti da `npm run study:generate`.
Non scrivere qui manualmente quiz o flashcard. Nessun contenuto dimostrativo
viene distribuito come materiale reale. Una cartella priva di JSON e valida.

Ogni raccolta conserva pagine estratte, citazioni, impronta del PDF,
modello, data e versione della procedura. Eseguire di nuovo il comando salta
le raccolte aggiornate; `--force` richiede esplicitamente una rigenerazione.
